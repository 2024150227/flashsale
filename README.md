# 高并发秒杀系统

基于 **FastAPI + MySQL + Redis + Kafka** 构建的企业级高并发秒杀系统，支持海量用户同时抢购，通过异步消息队列实现流量削峰，保障系统稳定性。

---

## 💡 核心技术亮点

### 一、高并发核心保障

| 技术                | 实现方式                      | 核心价值                   |
| ------------------- | ----------------------------- | -------------------------- |
| **Redis原子扣库存** | Lua脚本保证库存扣减原子性     | 杜绝超卖，确保数据一致性   |
| **Kafka异步订单**   | 下单入队，消费者异步处理      | 削峰填谷，支撑万级QPS      |
| **多级限流**        | SlowAPI接口限流 + Redis计数器 | 防止流量洪峰击穿系统       |
| **缓存预热**        | 秒杀前批量同步商品数据到Redis | 减轻DB压力，提升响应速度   |
| **读写分离**        | MySQL主从复制架构             | 读操作负载均衡，提升吞吐量 |

### 二、数据一致性保障

| 策略             | 实现细节                                         | 解决问题                       |
| ---------------- | ------------------------------------------------ | ------------------------------ |
| **最终一致性**   | Redis扣库存 → Kafka消息 → MySQL落库              | 高并发下的数据一致性           |
| **幂等性设计**   | 联合唯一索引 `(user_id, product_id, session_id)` | 防止重复下单和消息重复消费     |
| **用户去重拦截** | Redis Bitmap标记用户参与状态                     | 同一用户对同一商品只能抢购一次 |

### 三、性能优化策略

| 优化点             | 技术方案                 | 收益                       |
| ------------------ | ------------------------ | -------------------------- |
| **热点数据缓存**   | Redis缓存 + 随机过期偏移 | 消除缓存雪崩风险           |
| **Redis Pipeline** | 批量操作减少网络RTT      | 缓存预热效率提升300%+      |
| **布隆过滤器**     | 前置拦截无效请求         | 解决缓存穿透，拒绝恶意攻击 |

### 四、安全与可靠性

| 安全措施        | 实现方式                                  | 防护目标              |
| --------------- | ----------------------------------------- | --------------------- |
| **双Token认证** | Access Token(30分钟) + Refresh Token(7天) | 安全的会话管理        |
| **Token黑名单** | Redis实时存储已撤销Token                  | 支持即时登出          |
| **Redis持久化** | RDB+AOF混合模式                           | 快速恢复 + 数据不丢失 |
| **XSS防护**     | HTML转义处理用户输入                      | 防止跨站脚本攻击      |

### 五、业务功能亮点

| 功能             | 技术实现                  | 业务价值         |
| ---------------- | ------------------------- | ---------------- |
| **实时销量排行** | Redis ZSet实时更新        | 运营数据展示     |
| **UV统计**       | HyperLogLog去重计数       | 精准统计独立访客 |
| **智能客服**     | RAG知识库 + Ollama本地LLM | 7x24小时智能问答 |

## 🚀 快速开始

### 环境要求

- Docker 24.0+
- Docker Compose

### 启动服务

```bash
cd flashsale
docker-compose up --build -d
```

### 服务端口

| 服务      | 端口      | 说明       |
| --------- | --------- | ---------- |
| API服务   | 8000      | 主应用入口 |
| RAG服务   | 8001      | 智能客服   |
| MySQL主库 | 3307      | 写操作     |
| MySQL从库 | 3308      | 读操作     |
| Redis     | 6379      | 缓存       |
| Kafka     | 9092/9094 | 消息队列   |
| Ollama    | 11434     | 大模型服务 |

### 访问地址

- 秒杀首页: http://localhost:8000/flashsale
- 智能客服: http://localhost:8000/chat.html
- API文档: http://localhost:8000/docs

## 📝 核心业务流程

### 秒杀下单流程

```
用户请求 → API网关 → 限流检查 → Redis库存检查 → Kafka入队 → 返回排队中
                                                     ↓
                                          Kafka消费者 → Lua扣库存 → MySQL落库
```

### 订单取消流程

```
用户请求 → 订单验证 → 状态检查 → 更新状态 → Redis归还库存 → 返回成功
```
